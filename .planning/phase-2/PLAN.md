## 섹션 상세 내용

### 1. 요금제 섹션

**위치:** 사용방법 하단, 이용 후기 상단

**구조:**
```
┌─────────────────────────────────────────────────────────┐
│                    멤버십 요금제                         │
│                                                         │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐ │
│  │   무료 플랜  │    │  프리미엄    │    │  비즈니스   │ │
│  │    ₩0      │    │   ₩9,900    │    │  ₩19,900   │ │
│  │   /월       │    │   /월       │    │   /월       │ │
│  │             │    │  ★ 추천     │    │             │ │
│  └─────────────┘    └─────────────┘    └─────────────┘ │
└─────────────────────────────────────────────────────────┘
```

**내용:**
| 플랜 | 가격 | 기능 |
|------|-------|----------|
| 무료 | ₩0/월 | 기본 건강 기록, 1마리, 제한된 AI 상담 |
| 프리미엄 | ₩9,900/월 | 전체 기능, 무제한 동물, 우선 상담, 광고 없음 |
| 비즈니스 | ₩19,900/월 | 다중 사용자, 팀 관리, 맞춤 개발, 우선 지원 |

**생성할 컴포넌트:** `PricingCard.tsx`, `PricingSection.tsx`
